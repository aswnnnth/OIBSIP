# DATA ANALYTICS – LEVEL 1 – CUSTOMER SEGMENTATION

## 📌 Project Overview

This project was completed as part of the **Oasis Infobyte Data Analytics Internship (OIBSIP)**.

The project focuses on **Customer Segmentation** using **RFM (Recency, Frequency, Monetary) analysis** and **K-Means Clustering**. The objective is to identify different groups of customers based on their purchasing behaviour and provide targeted marketing recommendations.

## 🎯 Objective

The main objectives of this project are:

- Analyze customer purchasing behaviour
- Calculate Recency, Frequency, and Monetary (RFM) metrics
- Identify different customer segments using K-Means clustering
- Understand the characteristics of each customer segment
- Develop targeted marketing strategies based on customer behaviour

## 🔍 Project Workflow

### 1. Data Inspection

The dataset was inspected to understand:

- Number of rows and columns
- Data types
- Missing values
- Duplicate records
- Summary statistics

### 2. Data Cleaning

The following cleaning steps were performed:

- Removed duplicate records
- Removed rows with missing `CustomerID`
- Checked for remaining missing values
- Converted `InvoiceDate` into datetime format

### 3. Descriptive Analysis

Three customer behaviour metrics were calculated:

- Average Purchase Value
- Purchase Frequency
- Average Customer Lifetime Value (CLV)

### 4. RFM Analysis

Customer behaviour was measured using:

**Recency:** Number of days since the customer's last purchase.

**Frequency:** Number of unique purchases made by the customer.

**Monetary:** Total amount spent by the customer.

### 5. Outlier Removal

Outliers in the RFM dataset were identified and removed using the **Interquartile Range (IQR) method**.

### 6. Feature Scaling

The RFM variables were standardized using `StandardScaler` before applying clustering.

### 7. K-Means Clustering

The **Elbow Method** was used to determine an appropriate number of clusters.

K-Means clustering was then applied with **4 customer clusters**.

### 8. Cluster Analysis

The customer clusters were analyzed using:

- Cluster size
- Average Recency
- Average Frequency
- Average Monetary value
- Recency vs Monetary visualization
- Frequency vs Monetary visualization

## 💡 Customer Segments

The analysis identified four customer groups:

### Cluster 0 – High-Value Loyal Customers

- High purchase frequency
- High spending
- Recommended for loyalty programs, VIP offers, and exclusive discounts

### Cluster 1 – At-Risk Customers

- Customers who have not purchased for a long time
- Recommended for personalized emails, reminders, and win-back promotions

### Cluster 2 – Regular Customers

- Moderate purchasing behaviour
- Can be encouraged to make repeat purchases through recommendations and seasonal offers

### Cluster 3 – New or Low-Spending Customers

- Recently joined or relatively low spending
- Welcome discounts and cross-selling can help increase engagement

## 📈 Key Insights

- RFM analysis provides a useful way to understand customer purchasing behaviour.
- K-Means clustering grouped customers into four distinct segments.
- High-value customers can be targeted with loyalty and VIP programs.
- At-risk customers can be targeted with retention and win-back campaigns.
- New or low-spending customers can be encouraged through welcome offers and cross-selling.

## 📌 Marketing Recommendations

- Reward high-value customers with loyalty programs and exclusive offers.
- Use personalized campaigns to re-engage at-risk customers.
- Encourage regular customers to increase purchase frequency.
- Use welcome offers and cross-selling strategies for new or low-spending customers.
- Develop different marketing strategies for each customer segment rather than using a single strategy for all customers.
